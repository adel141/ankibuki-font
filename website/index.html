About the font

Sketchbook energy for Bangla display type

Ankibuki is a playful Bangla scribble display typeface inspired by doodles, sketchbooks, classroom notes, and expressive handwriting. It is designed for posters, children's books, social media graphics, event titles, and creative Bangla branding.

Embed Ankibuki

Use the webfont on your site

Host the WOFF2 file with your project, then load it with `@font-face` and apply the `Ankibuki` family to Bangla display text. 

@font-face {
  font-family: "Ankibuki";
  src: url("assets/fonts/Ankibuki-Regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

.bangla-display {
  font-family: "Ankibuki", sans-serif;
}
